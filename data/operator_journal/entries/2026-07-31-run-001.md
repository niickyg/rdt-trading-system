  analysis, signal combiner) is documented in detail but the directory is **empty**.
  The "$25K account" doesn't match reality. Treat the docs as intentions.

  on Yahoo Finance via `yfinance` (`backtesting/data_loader.py`), which returns HTTP
  429 (rate-limited) here, and there is no cached data. So I could not run or
  reproduce any backtest this run. IBKR MCP `get_price_history` is the reliable data
  source available to the operator and should become the backtest's data path.
