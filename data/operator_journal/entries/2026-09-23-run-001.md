## Honest edge estimate

**Best current estimate of net-of-cost annualized return: ~3–5%, versus SPY ~18% over the
same period. Net edge vs the benchmark: strongly negative (roughly −13 pp/yr).** The strategy
makes money in absolute terms (small positive) but loses decisively to passively holding SPY.
Transaction costs *reduce* the edge (from ~6% gross toward ~3–5% net) but are **not** the
main problem — the gross edge itself is a fraction of buy-and-hold. This is consistent with
`ACTIONABLE_100X_STRATEGY.md`'s own admission of a slightly-negative Kelly criterion.

## Disproven / dead ends (do not repeat)

- **"Add transaction costs to see if they erase the edge" — done.** They don't erase it; they
  shrink an edge that was already far below buy-and-hold. Re-running cost overlays alone
  won't change the verdict.
- **"RDT filters are a clear improvement" — not robust.** True in the old documented window,
  false in two of six windows here. Adding *more* confirmation filters is not a promising
  direction; it shrinks sample size against a benchmark it already loses to.
- **Raising risk-per-trade to lever returns — mathematically dead** (near-zero Kelly; scales
  ~0 expectancy by a bigger number). Do not "go aggressive" per the 100X docs.

## Recommendation for next instance

The single highest-value question: **Is there ANY market regime where this strategy beats SPY
net of costs?** All data examined so far is a strong bull market, where a trade-in/trade-out
long-biased system structurally cannot beat holding the index. The one intellectually honest
steelman for RRS is *choppy or bearish* regimes (it takes shorts; it sits out weak markets).
Next session:
1. Backtest the strategy vs SPY over a **flat/bearish window** (e.g. 2022, or 2018-Q4). If it
   still loses net of costs there, the negative verdict is regime-robust → **recommend
   wind-down / fundamental pivot to the human** per MANDATE §7.
2. If it *wins* in bear/flat regimes, the real product is a **regime-gated overlay** (hold SPY
   in bull, switch to the RRS engine only when SPY is below its 200-day) — test that combined
   equity curve vs pure buy-and-hold. That is the only path I currently see to beating the
   benchmark, and it should be proven before any more feature work.

Do NOT spend a session adding features, ML, or filters until (1) or (2) is answered. The bot
does not lack features; it lacks a demonstrated edge.
