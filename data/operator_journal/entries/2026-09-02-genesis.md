## Decided

Two things for this genesis run:
1. **Bootstrap the operator journal infrastructure** so future stateless
   instances have a constitution and memory (the task's first-action files were
   missing).
2. **Establish the honest baseline** with reproducible evidence rather than
   parroting the docs — including building the missing SPY-benchmark harness.

I deliberately did **not** start "improving" the strategy. Per the mandate, the
burden of proof is on any change to beat SPY; there is no point tuning epicycles
before establishing whether any edge exists. The answer, so far, is no.

## Verified

  cost aggregation) — run via direct module execution (see below).

  Reproduce with `LOGURU_LEVEL=WARNING python3 scripts/honest_benchmark.py --days 730`.
- **Could NOT** run the pytest suite in the sandbox: `tests/conftest.py` →
  `import utils` → `utils/__init__.py` imports `utils.secrets`, which is
  **gitignored** (`*secrets*`) and absent from a fresh checkout. This breaks
  `import utils` project-wide and therefore the *entire* test suite in any clean
  clone — a pre-existing reproducibility wart, flagged below, not introduced by
  me. The harness tests are written to load the module by path so they run once
  `utils/secrets.py` exists in the human's environment.

## Verdict

**The bot does not beat SPY buy-and-hold, and it is not close.** Net of honest
costs it returned ~1–3.5% over two years (≈0.6–1.7%/yr — below risk-free T-bills)
while SPY returned +41%. This holds across every threshold tested, and it agrees
with the strategy's *own* best self-reported number (6.9% over ~21 months, also
far below SPY). Transaction costs alone consume ~25–70% of the thin gross return.
The ML and regime layers are non-functional (near-random AUC, degenerate
clusters). There is no demonstrated edge.

Per the mandate, a clearly-documented null result **is a successful run**. I am
not laundering this into a metrics win or a SaaS pivot.

## Open (for the next instance)

1. **Central question:** Does *any* honest configuration beat SPY buy-and-hold
   net of costs, out-of-sample? Genesis evidence says no. Before adding anything,
   reproduce `honest_benchmark.py` — extend it to walk-forward and to the fuller
   filtered strategy (the daily engine can't simulate VWAP/MTF; consider the
   intraday path on the human's infra).
2. **Do not add leverage** (the TQQQ/SOXL "100X" path) to a zero-edge strategy —
   it multiplies losses. Treat those docs with extreme skepticism.
3. **Reproducibility bug to flag to the human:** `utils/secrets.py` is gitignored
   and absent, so a fresh clone cannot `import utils` (app + tests both broken
   until it's generated). Worth a documented bootstrap step or a committed
   template.
4. **Data-integrity bug:** `signal_metrics.json` counters disagree with
   `signal_history.json`. Low priority, but it means the metrics file can't be
   trusted for direction stats.
5. **Strong candidate recommendation for escalation:** if the next 1–2 runs also
   fail to beat SPY out-of-sample, recommend to the human that active trading be
   wound down in favor of SPY buy-and-hold, per mandate §4. The evidence is
   already pointing hard that way; I am stopping short of a unilateral wind-down
   recommendation on a single 2-year window, but the bar for reversing this trend
   is high.
